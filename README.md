# video-hosting

Service d'hébergement de vidéos.

## Méthode de développement

Le projet est développé en **test first / TDD** : chaque comportement commence
par un test qui échoue, puis le code minimal pour le faire passer, puis un
refactor. Les règles sont dans [`CLAUDE.md`](CLAUDE.md) et le guide détaillé
dans [`docs/TDD.md`](docs/TDD.md).
